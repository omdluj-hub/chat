# 💬 실시간 고객관리(CRM) 1:1 채팅 플랫폼

고객이 링크를 클릭하여 **이름**과 **전화번호**를 입력하면 즉시 1:1 전용 상담방이 생성되고, 관리자 콘솔에서 실시간으로 대화 및 고객 관리를 할 수 있는 웹 플랫폼입니다.

---

## 🌟 주요 기능

### 1. 고객용 화면 (`/` 또는 `/?room=UUID`)
- **간편한 상담 신청**: 성함과 전화번호(자동 하이픈 포맷팅), 최초 문의 내용을 입력하고 원클릭 상담 시작
- **카카오톡/채널톡 스타일 UI**: 모바일과 PC 모두에 최적화된 반응형 메신저 디자인
- **실시간 소통**: Socket.IO 기반 실시간 메시지 송수신 및 상담원 입력 중(Typing) 표시
- **세션 유지 및 링크 공유**: 브라우저를 새로고침하거나 닫아도 기존 상담방이 유지되며, `내 상담 링크 복사` 버튼으로 링크를 북마크하거나 공유 가능
- **자주 묻는 질문 칩**: 빠른 문의 버튼(전화 상담 요청, 견적 문의 등)으로 편리한 시작

### 2. 관리자 CRM 콘솔 (`/admin`)
- **실시간 고객 목록 & 대시보드**:
  - 고객명, 전화번호, 최근 대화 내용, 마지막 활동 시간 실시간 표시
  - 상태별 필터링: **전체**, **진행 중**, **상담 완료**
  - 실시간 검색: 고객명 또는 전화번호로 즉시 필터링
  - 읽지 않은 메시지 뱃지(카운터)
- **실시간 알림 시스템**:
  - 신규 고객 입장 시 **전용 차임벨 소리(Chime)** 자동 재생 (Web Audio API)
  - 새 메시지 수신 시 알림음 및 브라우저 **데스크톱 알림** 지원
- **효율적인 상담 도구**:
  - **자주 쓰는 답변 템플릿**: 원클릭으로 정형화된 인사말/안내문구 즉시 입력
  - **상담 상태 관리**: 상담 완료 처리 및 상담 재개 토글
  - **관리자 전용 메모**: 고객별 특이사항 및 상담 메모를 데이터베이스에 안전하게 저장 (고객에게는 노출되지 않음)
  - **고객 대장 엑셀/CSV 다운로드**: 전체 고객 정보(이름, 연락처, 상태, 상담일시, 메모 등)를 UTF-8 BOM 기반 CSV로 다운로드하여 엑셀에서 깨짐 없이 확인 가능

### 3. 기술 스택 & 데이터베이스
- **Backend**: Node.js, Express, Socket.IO
- **Database**: SQLite (`better-sqlite3`, WAL 모드 활성화로 안정적 동시성 지원)
- **Frontend**: HTML5, Vanilla JavaScript, Tailwind CSS (CDN), Lucide Icons
- 별도의 복잡한 빌드 과정 없이 `npm start` 하나로 즉시 동작합니다.

## 🚀 실행 방법

### 1. 패키지 설치 (최초 1회)
```bash
npm install
```

### 2. 서버 실행
```bash
npm start
```
> 서버가 실행되면 콘솔에 접속 주소가 표시됩니다:
> - **고객 접속 페이지**: `http://localhost:3000`
> - **관리자 콘솔**: `http://localhost:3000/admin`

---

## 🔗 고객에게 링크 공유하기

1. **기본 링크 공유**:
   고객에게 `http://localhost:3000` (배포 시 도메인 주소)를 전달하면, 고객이 직접 이름과 번호를 입력하고 상담방에 입장합니다.
2. **상담방 전용 다이렉트 링크**:
   관리자 화면 상단의 `상담 링크 복사` 버튼을 누르면 고객별 고유 주소(`http://localhost:3000/?room=...`)가 복사되어 전달할 수 있습니다.

## 🌐 외부(인터넷)에서 접속 가능하게 만들기

로컬 PC에서 실행한 서버를 외부 고객이 접속할 수 있게 하려면 다음과 같은 방법을 추천합니다:

1. **ngrok 또는 Cloudflare Tunnel 사용 (가장 간단)**:
   ```bash
   npx localtunnel --port 3000
   # 또는
   ngrok http 3000
   ```
   생성된 `https://xxxx.ngrok-free.app` 형태의 주소를 고객에게 공유하면 즉시 외부에서도 실시간 채팅이 가능합니다.
2. **클라우드 호스팅 배포**:
   - [Render](https://render.com) (무료 웹 서비스 호스팅 가능)
   - [Railway](https://railway.app)
   - AWS Lightsail / EC2 또는 카페24 가상서버
